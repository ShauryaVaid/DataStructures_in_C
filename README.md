# Data Structures in C

Welcome to the Data Structures in C repository. This repository contains a comprehensive collection of programs and exercises implementing various fundamental data structures and algorithms in the C programming language.

## Repository Structure

The codebase is organized systematically into directories based on progressive complexity and overarching topics:

- **Lab1 to Lab4**: Foundational C programming concepts, array manipulations, structures, and introductory algorithms.
- **LAB5**: Advanced structures and pointer manipulations.
- **oneFileforAll_(being_updated)**: End-to-end implementations of complex structures such as Polynomial operations and Sparse Matrices.
- **STACK**: Implementations of the Stack data structure using both Arrays and Linked Lists.
- **Root Directory**: Contains various standalone practice scripts and utility codes focusing on Linked Lists, Sparse Matrices, and structure memory allocations.

## Key Topics Covered

- Arrays and Strings
- Structures and Pointers
- Singly and Doubly Linked Lists
- Stacks (Array-based and Linked List-based)
- Sparse Matrices (Representation, Transpose, and Operations)
- Polynomial Representation and Addition using Linked Lists

## How to Compile and Run

To compile and run any of the C files, you can use the standard GCC compiler environment.

```bash
# Navigate to the specific directory or use the path directly
gcc -o program_name Lab1/22.7.26_LAB_1_Q1.c

# Run the compiled program (Windows)
program_name.exe

# Run the compiled program (Linux/Mac)
./program_name
```

This repository serves as a reference for standard data structure implementations in C. The source code represents hands-on practice, step-by-step problem-solving, and algorithmic implementation logic designed for academic and practical reference.
